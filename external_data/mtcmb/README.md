本目录仅使用 `TCM-CHGD.jsonl`（100 条）。

## 数据集构成（官方说明）
> 使用 DeepSeek-R1 根据官方病案摘要逆向生成模拟临床问诊对话作为模型输入；
> 经执业医师专家审核后，以原始官方答案作为标准输出。
> 来源：国家中医药管理局认证中心《中医执业助理/执业医师实践技能考试案例分析题库》。

## 本项目用途
仅用于"输入形态兼容性演示"（长对话 / 口语输入），**不做准确率评测**：
- TCM-CHGD 使用临床复合证名（如「风寒湿痹-着痹」）
- 本系统知识库使用教材证型名（如「风寒感冒」）
- 两者体系不同，无法自动判定对错

## 证型可映射情况
- 100 条中，证候诊断能映射到本项目 37 个教材证型的有 **9 条**
- 其余 91 条为临床复合证名，本项目知识库未收录
