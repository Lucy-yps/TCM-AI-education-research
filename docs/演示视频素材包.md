> **数据边界（演示时务必说明）：**舌脉训练收录同时满足以下条件的证型：(1) 病历数 >= 20；(2) 有 >= 2 个鉴别性舌脉特征（出现率 >= 40% 且在不超过 30% 的证型中出现）；(3) 舌脉特征覆盖 >= 2 个维度（舌质/舌苔/脉象）。符合条件者共 24 / 72 个核心证型。其余证型因舌脉特征与其它证型重叠过多或维度单一而排除——这反映中医舌脉需四诊合参、单个特征难以独立辨识的实际情况。
