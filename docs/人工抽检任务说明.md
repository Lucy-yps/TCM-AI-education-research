# 人工抽检任务说明

> **这是一份请中医专业同学协助审核的说明。可直接转发。**
> 对应文件：`人工抽检表_请中医专业审核.xlsx`（3 个 Sheet）

## 一、背景（一句话）

我们在做一个**中医辨证教学辅助系统**，它会自动从真实电子病历生成练习题、并从知识库中抽取治法方剂。
程序能做结构化校验（答案一致、选项规范），**但判断不了医学上是否正确**——所以需要请您帮忙把关。

## 二、最重要的一点

> **这不是考试，是帮我们找错。**

发现错误是我们**最想看到的结果**。错误率会被如实写进报告——我们不会因为错误多而扣您的面子，
反而会感谢您让我们发现了问题。**请不必客气，如实填写即可。**

## 三、数据从哪来

| 内容 | 来源 | 是否系统生成 |
|---|---|---|
| 题干病例 | TCM-SD 公开电子病历数据集（真实临床、已脱敏）| 原文，非生成 |
| 证型标注 | 数据集专家标注 | 原文，非生成 |
| 解析文字 | 大模型生成 | **是** |
| 治法方剂 | 大模型从知识库原文抽取 | **是** |

## 四、怎么填

打开 Excel，有 3 个 Sheet：

| Sheet | 内容 | 需要填什么 |
|---|---|---|
| `0-填写说明` | 说明 | 不用填，可先看一遍 |
| `1-辨证题目(20题)` | 20 道辨证选择题 | 4 列 |
| `2-方剂治法(20题)` | 20 条治法方剂 | 4 列 |

**浅黄色底色的列**是需要您填的（前三列是下拉框，点一下就能选，不用手打）。

### Sheet 1「辨证题目」要判断三件事

| 列 | 问题 | 怎么判断 |
|---|---|---|
| ① 答案是否正确 | 题干这个病例，对应的证型是不是「证型(标准答案)」那一列？ | 正确 / 存疑 / 错误 |
| ② 解析是否准确 | 解析里引用的症状、舌脉，跟病例对得上吗？有没有**硬编造**？ | 正确 / 存疑 / 错误 |
| ③ 干扰项是否合理 | 另外三个选项，是不是「容易混淆但确实不对」的证型？ | 正确 / 存疑 / 错误 |
| 综合判定 | 这道题整体能不能用 | 可用 / 需修改 / 不可用 |
| 备注 | 有任何想说的都写 | 自由填写 |

> **注意**：如果某个干扰项其实**也说得通**，请在这一列填「错误」，并在备注写明是哪个选项。
> 这种题对我们是**很重要的发现**——说明题目有歧义。

### Sheet 2「方剂治法」要判断两件事

| 列 | 问题 |
|---|---|
| ① 治法是否正确 | 系统给的治法，是该证型的规范治法吗？ |
| ② 主方是否正确 | 所列方剂是该证型的代表方吗？ |
| 综合判定 | 可用 / 需修改 / 不可用 |

> **提示**：同一证型在不同疾病中可能用不同方剂。若列出了多个方剂，
> 请按「**是否包含正确方剂**」来判断，不必要求全部匹配。

## 五、三个判定档的含义

| 判定 | 含义 |
|---|---|
| **正确** | 医学上没问题，可以直接用 |
| **存疑** | 基本对，但描述不够典型 / 病例信息不足 / 教材版本有差异 |
| **错误** | 明显不对 |

**如果某道题您也不确定，填「存疑」就好，不必勉强判断。**

## 六、耗时

每题约 1~2 分钟，**40 题合计约 40~60 分钟**。

如果时间有限，**只抽做一半也可以**（比如 Sheet1 做 10 题、Sheet2 做 10 题），
我们在报告里会注明实际抽检数量。

## 七、填完之后

把 Excel 发回即可。我们会用脚本汇总，生成一份《人工抽检结果报告》，包含：

- 抽检题数、正确 / 存疑 / 错误的数量与比例
- **抽检准确率**（= 判定"正确"的题数 / 抽检题数）
- 判定为错误的题目明细（如有）

这份报告会作为作品的**效果验证依据**提交，并在报告中**如实注明抽检为随机抽样、
结论仅代表抽检范围**。

## 八、常见疑问

**Q：病例里有些描述看起来不太规范，是你们改的吗？**
A：不是。题干是电子病历原文（部分为真实临床记录，文字未必规范）。这恰恰是我们想验证的——
系统能否处理真实世界的"不完美"文本。

**Q：如果我认为标准答案本身就错了呢？**
A：请填「错误」并在备注说明。**数据集标注也可能有误**，您的意见对我们很有价值。

**Q：需要写很长的备注吗？**
A：不必。一句话就够，比如"此法偏凉，虚寒证不宜"。
