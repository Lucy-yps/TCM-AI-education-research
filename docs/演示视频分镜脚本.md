# 演示视频分镜脚本

> **官方要求**：MP4 格式，时长 **3-5 分钟**，大小 ≤300MB，清晰展示**作品功能、实现流程与应用效果**。
> 本脚本设计为 **约 4 分 45 秒**（留余量）。

## ⚠️ 录制前必读：公平性红线

> 官方原文：「作品材料（作品方案、**演示视频**、答辩PPT等）中均**不得出现参赛团队所在学校名称及Logo、指导教师等信息**」

| 必须检查 | 说明 |
|---|---|
| 桌面壁纸 / 文件路径 | 不能出现校名 |
| 浏览器标签页 / 书签栏 | 关掉含校名的页面 |
| 录屏窗口标题栏 | 路径别带校名 |
| 口播内容 | 不要说学校名、指导教师名 |
| 视频片头/片尾 | 不放校徽、校名 |

**建议**：录制前把项目复制到干净目录（如 `D:\demo`），桌面换纯色壁纸。

## 录制准备

| 项目 | 建议 |
|---|---|
| 录屏工具 | Windows 自带 Win+G，或 EV 录屏 / OBS |
| 分辨率 | **1920×1080**（1080p）|
| 浏览器 | Chrome / Edge，按 **F11 全屏**，Ctrl+Shift+B 隐藏书签栏 |
| 服务 | 先双击 `启动.bat`，确认 http://127.0.0.1:5000 可访问 |
| 字号 | 浏览器 Ctrl+加号 放大到 **125%** |
| 鼠标 | 移动**慢**一点；点击后停 1 秒再继续 |

## 分镜表

### 第 1 幕｜开场：问题是什么（0:00 - 0:30）

| 项 | 内容 |
|---|---|
| **画面** | 知识检索首页全景（导航栏 + 输入框）|
| **操作** | 1. 打开 http://127.0.0.1:5000（F11 全屏）<br>2. 鼠标缓慢划过导航栏（6 个入口）<br>3. 停在输入框 |
| **旁白** | 中医诊断学教学中，学生要把患者口语化的症状，对应到教材里的规范证型。同一件事，患者说「没胃口」，教材写「食少纳呆」；说「拉肚子」，教材写「大便泄泻」。这中间缺少一个能即时验证的工具。 |

### 第 2 幕｜核心功能：口语 → 证型（0:30 - 1:30）

| 项 | 内容 |
|---|---|
| **画面** | 检索结果卡：候选证型、命中证据、置信度分级 |
| **操作** | 1. 输入框中粘贴或念：`我这两天有点发烧，体温偏高，稍微怕风，喉咙痛，鼻涕是黄的，咳出来的痰也是黄的`<br>2. 点「知识检索与证型辨析」<br>3. **停顿 3 秒**让评委看清结果<br>4. 鼠标依次指向：候选证型 → 命中症状词 → 置信等级 |
| **旁白** | 系统给出了候选证型，并且展示了判断依据——哪些症状词被命中了、哪些没有被识别。更重要的是置信等级：它不是简单给一个答案，而是告诉我们这个答案有多可靠。证据充分时标注较可靠，证据不足时会明确提示。 |

### 第 3 幕｜⭐ 创新点一：证据不足时拒答（1:30 - 2:15）

| 项 | 内容 |
|---|---|
| **画面** | 拒答提示 + 缺失信息说明 |
| **操作** | 1. 清空输入框<br>2. 只输入 4 个字：`患者腹痛`<br>3. 点检索<br>4. **停顿 4 秒**（这一幕是重点）<br>5. 鼠标指向「证据不足」标签与拒答说明 |
| **旁白** | 如果只输入「患者腹痛」，系统不会硬猜，它会拒绝给出结论，并说明缺少什么信息。这是我们刻意设计的机制：分类器概率低于 0.50 的那一档，实测准确率只有 55%，接近抛硬币，所以系统选择不下结论。这个拒答机制本身，就是给学生的临床思维示范——证据不足时，不该下结论。 |

### 第 4 幕｜⭐⭐ 创新点二：相似证型鉴别（2:15 - 3:15）

| 项 | 内容 |
|---|---|
| **画面** | 对比页：两个证型的特征症状 + 出现率百分比 |
| **操作** | 1. 点导航「相似证型鉴别」<br>2. 证型 A 选 `湿热瘀阻证`，证型 B 选 `湿热蕴结证`<br>3. 点「开始对比」<br>4. **停顿 3 秒**<br>5. 鼠标指向两栏特征症状的百分比 |
| **旁白** | 学生最大的困难不是不知道证型，而是分不清相近的证型。这里对比「湿热瘀阻证」和「湿热蕴结证」——两个证型在教材上的定义很像，但系统给出的是真实病历统计：湿热瘀阻证 93% 出现月经相关症状，湿热蕴结证 58% 出现黄疸。这些差异不是编的，是从两万多条真实电子病历里统计出来的。 |

### 第 5 幕｜教学闭环：出题 → 答题 → 学习报告（3:15 - 4:00）

| 项 | 内容 |
|---|---|
| **画面** | 训练页出题 → 答题 → 学习报告 |
| **操作** | 1. 点「辨证训练」<br>2. 点「出题」（等约 3 秒）<br>3. **故意点一个错误选项**<br>4. 展示解析与干扰项辨析（停 2 秒）<br>5. 点「学习报告」，展示「易混淆证型对」 |
| **旁白** | 辨证训练模块从真实病历自动生成题目。注意解析部分——它逐条说明为什么其他选项不对。答题记录会进入学习报告，系统据此统计出这个学生最容易混淆的证型对，形成练、评、补的闭环。 |

### 第 6 幕｜⭐ 数据说明（4:00 - 4:30）

| 项 | 内容 |
|---|---|
| **画面** | 一张数据图（建议提前做成 PPT 或图片）|
| **操作** | 切换到数据页，**停留 10 秒以上**让评委看清 |

**数据页内容（照抄即可）**：

```
评测集：TCM-SD 去泄漏 683 例（16 类对齐）

  本作品分类器           93.0%   [95% CI: 90.8% ~ 94.7%]
  ---------------------------------------------
  DeepSeek 零样本        75.8%   [95% CI: 72.5% ~ 78.9%]
  多数类基线             77.3%   （永远答样本量最大的证型）

  分类器 vs 大模型零样本：+17.2 个百分点（z = 8.78，统计显著）
  大模型零样本 vs 多数类基线：无统计差异（z = -0.64）
```

| **旁白** | 在 683 条去泄漏的真实病历上，我们的轻量分类器达到 93.0%。作为对照，通用大模型零样本是 75.8%，而「永远回答样本量最大的证型」这个最笨的基线是 77.3%。也就是说，大模型在这个任务上并没有超过最笨的基线。这说明在垂直领域的标准体系内，域内监督模型仍然有不可替代的价值。 |

### 第 7 幕｜收尾（4:30 - 4:45）

| 项 | 内容 |
|---|---|
| **画面** | 回到首页 |
| **操作** | 切回首页即可 |
| **旁白** | 整个系统完全离线运行，不需要 GPU，普通笔记本就能部署。知识库可以整体替换，因此这套方法也能迁移到方剂学、针灸学等其他中医课程。 |
