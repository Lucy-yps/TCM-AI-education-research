## 二、借鉴的方法（文献 1）

原论文核心发现：

> "We identify a model-dependent failure mode of **entropy-based uncertainty** methods that leads to unreliable abstention behaviour, and address it by **combining entropy scores with a correctness probe signal**."

```
combined = α · (1 - H_norm) + (1-α) · probe     # probe = P(判断正确 | 不确定性特征)
```

## 三、本项目的适配（与原文的差异）

| 维度 | 原论文 | 本项目 |
|---|---|---|
| **任务** | 开放域问答（TriviaQA/BioASQ/MedicalQA）| **中医证型辨识（16 类闭集分类）** |
| **数据** | 公开 QA 基准 | **TCM-SD 真实电子病历** |
| **模型** | 四个 LLM 家族 | TF-IDF + LogisticRegression |
| **探针输入** | 模型输出信号 | 分类器概率分布的 5 维不确定性特征 |

探针特征（5 维，均不依赖标签）：`p_max`、`H_norm`、`1-H_norm`、`margin`、`var(p)`

**防泄漏设计**：

| 用途 | 数据来源 | 样本量 |
|---|---|---|
| 探针拟合 | train.json（16 类子集）| 3,000 |
| 阈值校准 | train.json 其余 | 3,000 |
| **评测** | tcm_sd_test.json 去泄漏子集 | **686** |

> 测试集与训练集无文本重叠（按"主诉+现病史+四诊"拼接后精确匹配，剔除 8 条）。

## 四、实验结果

### 4.1 不确定度信号的判别力

| 信号 | 校准集 AUC | 测试集 AUC |
|---|---|---|
| **正确性探针** | 0.9028 | **0.9114** |
| p_max（现有策略）| 0.8986 | 0.9097 |
| 1 - H_norm（纯熵）| 0.8838 | 0.9025 |

### 4.2 最优权重

```
alpha* = 0.0  （拟合集 AUC 0.9257；校准集独立复核一致）
```

> **诚实说明**：alpha=0 时组合分数退化为 p_max，说明**本任务上 p_max 已是最强单一信号**，探针未带来额外增益。这与原论文在开放域问答上的结论不同。

| 90% | 0.9692 (617) | 0.9676 (617) | 0.9692 (617) |

## 五、结论（如实报告）

### 5.1 得到支持的结论

| 结论 | 证据 |
|---|---|
| ✅ **纯熵在本任务上表现最差**，支持原文"熵不足"的论断 | 熵的 AUC 最低（0.9025）；99.5% 目标准确率下覆盖率仅 49.9% |
| ✅ **正确性探针是可用的不确定性信号** | 测试集 AUC 0.9114，为三种信号中最高 |
| ✅ **高精度区间存在实际增益** | 99.5% 目标准确率下，组合覆盖 **60.8%** vs 仅概率 58.7%（**+2.1 个百分点**）|

### 5.2 未达预期的部分

| 观察 | 说明 |
|---|---|
| ⚠️ **整体增益有限** | 权重最优化得 alpha=0（拟合集与校准集一致），组合退化为 p_max |
| ⚠️ **探针优势不显著** | AUC 仅高 0.0017，处于统计噪声量级 |
| ⚠️ **与原论文结论不一致** | 原文在开放域 QA 上组合显著优于纯熵；本任务三信号差距远小于原文 |

### 5.3 对系统的影响

| 场景 | 建议 |
|---|---|
| **常规使用（覆盖率 >70%）** | 维持现有 p_max 阈值策略（0.87 / 0.70 / 0.50）——简单、可解释、性能相当 |
| **高合规场景（目标准确率 ≥99.5%）** | 启用组合信号，可多保留约 2.1% 样本 |

## 六、为什么这个"未达预期"的结果仍有价值

1. **首次在中医证型辨识上检验选择性预测方法**——原论文未涉及中医或闭集分类场景
2. **给出了真实的失效边界**：来自开放域 QA 的方法**不能直接迁移**到垂直领域闭集分类
3. **找到原因线索**：本任务类别少（16 类）、高度不平衡（气滞血瘀占 77%）、分类器已接近性能上限（93%），不确定性信号的区分空间本就有限
4. **留下可复用的评估框架**：风险-覆盖曲线 + 覆盖率-准确率反向指标

> 报告未达预期的结果与报告成功结果同等重要——这是学术规范的要求。
