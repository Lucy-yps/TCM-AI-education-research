## （一）项目概述

### 1. 背景与意义

中医诊断学的教学核心，是让学生把**患者口语化的症状描述**对应到**规范证型**，并理解每个证型的证据构成。
这一环节存在三个现实困难：

- **术语断层：**患者说"没胃口"，教材写"食少纳呆"，学生需要在两套语言间建立映射，却缺少可即时验证的工具。
- **证据不可见：**通用大模型能给出证型名，却说不清依据了哪些症状，学生无法据此学习辨证思路。
- **方法认知偏差：**口语描述与电子病历文本分布差异极大，同一方法准确率可从 91.9% 跌到 12.7%，而这一现象在教学中几乎无法用传统手段演示。

### 2. 核心目标

| 目标 | 指标 | 达成情况 |
|---|---|---|
| 提升证型查阅效率 | 单条查询由分钟级降至毫秒级 | 实测约 0.05 秒/条 |
| 让证据可追溯 | 每条候选展示命中的症状词与未识别文本 | 已实现 |
| 让不确定性可见 | 置信度按参考集实测准确率分级，证据不足时拒答 | 已实现（拒答线概率 < 0.50）|
| 让方法差异可教学 | 内置五种方法对比与分布路由演示 | 已实现 |
| 支撑辨证训练 | 从真实病历自动生成带解析的训练题 | 已实现（题库 151 题）|
| 让结论可复现 | 全部实验脚本化，逐条原始输出留存 | 已实现 |

## （二）需求分析

> 完整分析见《需求分析.md》。此处摘要。

### 1. 学科专业界定

**学科领域：**中医学　**专业方向：**中医诊断学、中医内科学　**核心环节：**教学（课堂讲授与课后自学）与科研（证型相关数据的候选标注）。

### 2. 核心痛点

| 痛点 | 表现 | 量化依据 |
|---|---|---|
| 术语鸿沟 | 口语与规范证型术语缺少稳定映射 | 教材体术语覆盖密度 19.6%，病历体仅 2.6% |
| 证据缺失 | 只给结论不给依据，学生无法学习辨证过程 | 大模型零样本输出均为单一证型名，无证据说明 |
| 过度自信 | 工具不区分"有把握"与"在猜" | 分类器概率 < 0.50 区间实测准确率仅 55.4% |
| 分布失配被忽视 | 同类方法在不同文本上表现反转 | TF-IDF 口语体 91.9% / 病历体 12.7%；分类器 5.4% / 93.0% |
| 练习题目稀缺 | 优质辨证题依赖教师手工编写，成本极高 | 人工出题约 30~60 分钟/题 |

### 3. AI 赋能切入点

1. **术语归一** —— 同义词映射 + 检索算法（自然语言处理）
2. **证据抽取** —— 从输入中定位命中的知识库词条（可解释检索）
3. **不确定性量化** —— 按参考分布实测准确率给出置信等级（模型校准）
4. **题目生成** —— 从真实病历自动生成带解析的训练题（生成式 AI + 规则约束）

                             │
┌────────────────────────────▼────────────────────────────────────┐

**分层职责：**

| 层 | 职责 | 关键实现 |
|---|---|---|
| 展示层 | 知识检索与辨证训练两个界面 | 原生 JS，无构建步骤 |
| 服务层 | 参数校验、编排、模型并发调用 | Flask + CORS |
| 算法层 | 检索、分类、路由、校准、拒答、出题 | retrieval.py + quiz.py |
| 模型与数据层 | 静态知识、训练产物、校准表、出题池 | 均可离线，无外部依赖 |

### 2. 技术选型依据

| 环节 | 选型 | 与学科需求的适配理由 |
|---|---|---|
| 术语归一 | 规则映射表（107 条） | 教学场景需可解释，每条映射可人工核对 |
| 口语检索 | 词项 F1 / BM25 / TF-IDF / RRF | 无需训练、可离线、命中项可展示 |
| 病历分类 | TF-IDF(char_wb 1-2gram) + 逻辑回归 | 7.6 MB、7 ms，适配无 GPU 的课堂电脑 |
| 风格路由 | 可解释规则（3 个特征） | 判据可向学生解释，准确率 99.95% |
| 置信度 | 参考分布分箱 + 保序回归 | 各方法分数量纲不同，固定阈值无意义 |
| 出题生成 | 大模型 + 知识库约束 | 生成与判定分离，答案锚定权威知识 |

### 3. 核心技术模块

| 模块 | 实现思路 | 对应学科需求 |
|---|---|---|
| 术语归一 | 最长优先替换 107 条口语→规范词映射 | 解决术语鸿沟 |
| 风格路由 | 知识库词覆盖密度 + 数字密度 + 病历结构词加权 | 让学生理解"方法适用性取决于数据分布" |
| 检索与分类 | 五方法并行评估，按路由结果选用 | 提供可解释证据 |
| 置信度校准 | 参考语料分箱 → 实测每档准确率 → 保序回归平滑 | 让不确定性可见 |
| 拒答与降级 | 主方法置信不足时回落检索候选并标注 | 演示"证据不足不下结论" |
| 出题引擎 | 出题池抽样 → 大模型生成 → 6 项结构校验 → 选项随机化 | 解决练习题稀缺 |
| 相似证型鉴别 | 知识库概念相似度 + 真实病历症状谱差异 | 解决"分不清相近证型"这一核心难点 |
| 学习进度追踪 | 答题记录 → 按证型聚合 → 薄弱点与混淆对识别 | 形成"练—评—补"教学闭环 |
| 方剂治法联想 | 知识库治法方剂文本 → 大模型结构化抽取 → 相似证型作干扰项 | 辨证之后的论治环节 |
| 舌脉辨识 | 真实病历舌脉统计 → 鉴别力评分筛选 → 四诊基本功训练 | 舌脉对应记忆 |

**出题引擎的"生成与判定分离"设计（关键）：**

| 环节 | 由谁决定 | 说明 |
|---|---|---|
| 标准答案 | **病历标注 + 证型知识库** | 不由大模型自由发挥 |
| 题干文字 | 大模型 | 把真实病历改写成题面 |
| 干扰项 | 知识库候选池（同范畴相近证型）| 禁止自造证型名 |
| 选项位置 | **程序随机打乱** | 防止"答案总在 A" |
| 质量校验 | 程序（6 项核心 + 2 项加分）| 答案一致性、白名单、干扰项来源 |

## （四）方案可行性

### 1. 技术可行性

- **技术成熟度：**全部依赖为成熟开源库（Flask、scikit-learn、rank_bm25），无自研底层组件，无 GPU 需求。

## （六）应用效果

> 完整验证数据见《评测方法与结果说明.md》《出题质量验证报告.md》。

### 1. 检索与分类效果

| 方法 | 准确率 | 95% 置信区间 | 评测条件 |
|---|---|---|---|
| 多数类基线 | 77.3% | [74.0%, 80.2%] | 参照 |
| 大模型 DeepSeek 零样本 | 75.8% | [72.5%, 78.9%] | 域外零样本 |
| **本作品分类器** | **93.0%** | [90.8%, 94.7%] | 域内监督 |

分类器相对大模型零样本领先 **17.2 个百分点（z=8.78，显著）**；
大模型零样本与多数类基线**无统计差异（z=−0.64）**。

### 2. 出题效果

| 指标 | 数值 |
|---|---|
| 题库规模 | 151 题 |
| 核心校验通过率 | **100%**（6 项）|
| 覆盖证型 | 65 / 72 核心池 = 90.3% |
| 答案位置分布 | A 25.3% / B 25.3% / C 18.0% / D 31.3% |
| 生成速度 | 0.7 秒/题（并发 5）|
| 重复出题 | 0 组 |

### 3. 模块覆盖与数据边界（重要）

| 练习模块 | 可用证型 | 数据基础 | 边界说明 |
|---|---|---|---|
| 辨证训练 | 72（核心池）| 26,474 条真实病历 | 由大模型生成题干，程序校验 |
| 方剂治法 | 68 / 72 | 知识库治法方剂文本（253 段）| 4 个证型原文缺方剂数据 |
| 舌脉辨识 | **24 / 72** | 真实病历舌脉统计 | 见下 |

**舌脉辨识为何只有 24 个证型：**筛选条件为①病历数 ≥20；②有 ≥2 个鉴别性舌脉特征（出现率 ≥40% 且在 ≤30% 的证型中出现）；③覆盖 ≥2 个维度（舌质/舌苔/脉象）。其余证型的舌脉与其它证型重叠过多——**这反映了中医"舌脉需四诊合参、单个特征难以独立辨证"的实际情况，而非数据缺陷。**本作品不掩盖这一边界，在界面上明确标注。

### 4. 教学闭环效果

| 环节 | 功能 | 产出 |
|---|---|---|
| 练 | 辨证训练（157 题）| 从真实病历生成的带解析训练题 |
| 评 | 学习进度追踪 | 各证型掌握度、薄弱证型、易混淆证型对 |
| 补 | 相似证型鉴别 | 针对薄弱点的对比学习材料 |

**相似证型鉴别的数据基础：**核心池 72 个证型、2,556 组配对、666 个症状词表（已过滤 15 个通用词）；
差异特征来自 26,474 条真实病历的症状出现率统计。

**一个真实发现：**知识库中有 4 组证型的定义完全一致（如**肝气犯胃证 / 肝胃不和证**，
概念相似度 1.000）——这在国标体系中属于同义词对。本功能对此明确标注"同义词对"，
并展示二者在真实病历中的统计差异，而不是编造鉴别点。

## （七）总结与展望

### 1. 方案总结

**核心亮点：**

- **把"方法适用性"做成可演示的实验** —— 量化了同一方法在两类文本上的结论反转（91.9% vs 12.7%），并用可解释判据实现路由；
- **把"不确定性"做成教学内容** —— 置信度按参考集实测准确率分级，证据不足时拒答；
- **把"生成与判定分离"落到出题系统** —— 标准答案由知识库锚定，模型只负责文字表达，程序负责校验与随机化；
- **把"可复现"做成基本要求** —— 全部实验脚本化，逐条原始输出留存。

**客观不足：**

- 分类器仅覆盖 16 / 37 个证型，其余 21 类只能由检索给出候选；
- TCM-SD 官方划分非患者级，存在可见文本重叠（已剔除后重测）；
- 大模型仅测零样本，未测少样本与微调；
- 出题质量仅经程序结构化校验，**医学正确性尚需专业人员抽检**；
- 尚未开展正式教学试点。

### 2. 未来展望

| 方向 | 计划 |
|---|---|
| 数据 | 建立经授权、专家双人标注的数据集，采用患者级独立划分 |
| 模型 | 补充少样本与微调基线；引入中文句向量检索做消融 |
| 出题 | 完成人工抽检并公布准确率；扩展至全部 72 个核心证型 |
| 教学 | 落地课堂试点，采集学习效果数据；开发错题本与薄弱点追踪 |
| 推广 | 抽象为通用"分布路由 + 校准"框架，迁移到其他学科 |
