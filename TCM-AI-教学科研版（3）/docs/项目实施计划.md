# 项目实施计划

## 一、项目定位与目标

**项目名称：**本草辨证——面向中医教学与科研的知识检索辅助工具

**核心定位：**面向中医专业教学与科研场景的知识检索与辨证训练辅助工具。**不是医疗器械、诊断系统或处方工具，不构成医学诊断，不作为临床决策依据。**

**项目目标：**
1. 知识库建设：覆盖 37 个证型条目（后扩展至 72 个核心证型池）、248 个症状词、107 条口语→规范词映射。
2. 检索性能：口语体 TF-IDF 检索 Top-1 ≥ 90%（实际达成 91.9%）；病历体分类器 Top-1 ≥ 90%（实际达成 93.0%，95% CI: 90.8%~94.7%）。
3. 风格判定：知识库词覆盖密度 + 数字密度 + 病历结构词判据，准确率 ≥ 99%（实际达成 99.95%）。
4. 置信度与拒答：按实测准确率校准，概率 < 0.50 时拒答。
5. 辨证训练：从 54,152 条病历出题，题库 151 题，覆盖 65/72 核心证型，核心校验通过率 100%。
6. 系统可用性：本地完全离线运行，普通笔记本即可部署。

## 六、风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| TCM-SD 划分非患者级 | 评测指标可能偏高 | 已度量并剔除可见文本重叠（694→683），下一阶段建立患者级划分 |
| 分类器覆盖缺口（16/37 类） | 部分证型无法被分类器识别 | 界面明确披露未覆盖证型，检索方法作为补充；辨证训练模块独立于分类器 |
| 大模型 API 不稳定 | 出题与摘要功能不可用 | 本地题库已包含 151 道可复用题目；检索/分类/图谱完全离线 |
| 缺少一线用户试点 | 应用效果验证不足 | 本期未开展，已制定完整方案，列为下一阶段计划（见第七节） |
| 部分模块覆盖范围有限 | 舌脉辨识仅 24/72 个证型可用 | 遵循中医理论，仅在 ≥2 个鉴别性特征、覆盖 ≥2 维度的证型上出题；其余明确排除并注明原因 |

## 七、关于小规模试点的说明与下一阶段计划

**本期未开展正式的小规模教学试点。**

原因如下：
1. 团队三人均为软件工程专业，缺乏稳定、直接的中医专业教学场景入口，组织学生试用需要额外协调教师与课时；
2. 项目周期聚焦于算法验证、系统原型开发与可复现评测，已优先完成离线技术指标、大模型对照与系统功能自测。

作为替代，本阶段已完成以下验证工作（详见《应用效果验证.md》）：
- 离线技术指标：口语体 TF-IDF 检索 Top-1 91.9%，病历体分类器 Top-1 93.0%；
- 分布路由有效性：风格判定准确率 99.95%；
- 大模型对照：本地分类器 93.0% vs DeepSeek 零样本 75.8%，领先 17.2 个百分点；
- 出题质量：题库 151 题，核心校验通过率 100%；
- 系统功能：本地离线运行，响应 <0.1 秒/条，安全边界明确。

**下一阶段试点计划：**
- 对象：中医专业本科生或规培医师 10~20 人；
- 任务：给出 20 条口语症状描述，先手工查证型并计时，再用本工具查询并计时；使用辨证训练模块完成 10 道题；
- 采集：单条耗时对比、对“证据展示”与“置信度提示”的主观评分（1~5 分）、开放性意见；
- 产出：一页《试点反馈汇总》，作为后续版本的应用效果补充依据。

## 八、总结与展望

本作品已完成面向中医教学科研场景的知识检索、风格路由、置信度校准、拒答机制与辨证训练系统，并配套可复现的评测与基线对比。下一阶段将建立经授权、专家标注的患者级独立数据集，采用患者级独立划分，在冻结测试集上与基线对比，并开展小规模教学试点，进一步验证工具在教学场景中的实际效果。
