## 一、单题成本（实测）

| 项目 | 数值 | 说明 |
|---|---|---|
| 模型 | `deepseek-flash` | 调用 `deepseek-chat` 时由服务端路由至该模型 |

## 二、官方单价（DeepSeek 价目表）

| 计费项 | 空闲时段 | 高峰时段 |
|---|---|---|
| 输入（缓存未命中）| 1 元/百万 tokens | 2 元/百万 tokens |
| 输入（缓存命中）| 0.02 元/百万 tokens | 0.04 元/百万 tokens |

## 四、与传统出题方式对比

> 人工出题成本取决于教师薪酬水平，此处给出换算方法而非固定结论，评审可按本校实际标准代入。

| 对比项 | 人工编写 | 本方案 |
|---|---|---|
| 单题耗时 | 约 30~60 分钟（真实病例改写 + 干扰项设计 + 解析撰写）| **0.7 秒**（实测，并发 5）|
| 438 题所需人力 | 约 219~438 小时 | 1.8 分钟（实测 150 题用时 110 秒，线性外推）|
| 438 题 API 成本 | — | **1.5~2.9 元** |
| 质量一致性 | 依赖出题人状态，波动大 | 结构化校验 100% 通过，答案锚定知识库 |
| 可追溯性 | 依赖出题人记录 | 每题绑定来源病历（文件+行号）与知识库依据 |

**换算示例**（请按实际薪酬代入）：若人工出题折算时薪为 X 元/小时，438 题的人工成本约 `219X ~ 438X` 元；
本方案同等规模的模型调用成本为 1.5~2.9 元，不含硬件投入。

## 五、本地推理成本（不产生 API 费用）

| 组件 | 资源占用 | 单次耗时 | 说明 |
|---|---|---|---|
| 检索与风格路由 | 纯 CPU，无 GPU | 约 61 ms | TF-IDF 检索 |
| 证型分类器 | 7.6 MB 模型文件 | 约 7 ms | 逻辑回归，可完全离线 |
| 知识图谱 | 静态数据 | 即时 | 321 节点 / 344 关系 |

**结论：**知识检索、证型辨析、置信度校准、拒答判定**全部在本地完成，零 API 费用、零 GPU 需求**；
仅"生成新题"与"教学性证据摘要"两个可选功能需要联网调用大模型。

## 七、测算方法（可复现）

```
# 1. 实测单题 token 消耗
python scripts/cost_probe.py <项目目录>     # 输出 docs/_cost_probe.json

# 2. 批量生成题库（记录总耗时）
python scripts/batch_generate.py <项目目录> 438 5

# 3. 质检报告
python scripts/qc_report.py <项目目录> 20
```

**费用计算公式：**

```
总费用 = 输入tokens × 输入单价 + 输出tokens × 输出单价
       = 665 × 题数 × 输入单价 + 667 × 题数 × 输出单价
```
