# 项目实施计划

## 一、项目定位与目标

**项目名称：**本草辨证——面向中医教学与科研的知识检索辅助工具

**核心定位：**面向中医专业教学与科研场景的知识检索与证型辨析辅助工具。服务对象为中医专业学生、规培医师与科研人员，用于证型知识查阅、证据追溯与检索方法教学。不是医疗器械、诊断系统或处方工具，不构成医学诊断，不作为临床决策依据。

**项目目标：**
1. 知识库建设：覆盖 37 个证型条目、248 个症状词、107 条口语→规范词映射。
2. 检索性能：口语体 TF-IDF 检索 Top-1 ≥ 90%（实际达成 91.9%）；病历体分类器 Top-1 ≥ 90%（实际达成 93.0%）。
3. 风格判定：知识库词覆盖密度 + 数字密度 + 病历结构词判据，准确率 ≥ 99%（实际达成 99.95%）。
4. 置信度与拒答：按实测准确率校准，概率 < 0.50 时拒答，降级为候选线索。
5. 系统可用性：本地完全离线运行，普通笔记本即可部署，响应时间 ≤ 0.1 秒/条。

| 六、置信度校准 | 第 6 周 | 按参考分布分箱实测准确率，替换固定阈值；设置拒答线。 | calibration_data.json |

## 七、关于小规模试点的说明与下一阶段计划

**本期未开展正式的小规模教学试点。**

原因如下：
1. 团队三人均为软件工程专业，缺乏稳定、直接的中医专业教学场景入口，组织学生试用需要额外协调教师与课时；
2. 项目周期聚焦于算法验证、系统原型开发与可复现评测，已优先完成离线技术指标、大模型对照与系统功能自测。

作为替代，本阶段已完成以下验证工作（详见《评测方法与结果说明.md》《出题质量验证报告.md》）：
- 离线技术指标：口语体 TF-IDF 检索 Top-1 91.9%，病历体分类器 Top-1 93.0%；
- 分布路由有效性：风格判定准确率 99.95%；
- 大模型对照：本地分类器 93.0% vs DeepSeek 零样本 75.8%，领先 17.2 个百分点；
- 系统功能：本地离线运行，响应 <0.1 秒/条，知识图谱加载正常，安全边界明确。

**下一阶段试点计划：**
- 对象：中医专业本科生或规培医师 10~20 人；
- 任务：给出 20 条口语症状描述，先手工查证型并计时，再用本工具查询并计时；
- 采集：单条耗时对比、对“证据展示”与“置信度提示”的主观评分（1~5 分）、开放性意见；
- 产出：一页《试点反馈汇总》，作为后续版本的应用效果补充依据。

## 八、总结与展望

本作品已完成面向中医教学科研场景的知识检索、风格路由、置信度校准与拒答机制，并配套可复现的评测与基线对比。下一阶段将建立经授权、专家标注的数据集，采用患者级独立划分，在冻结测试集上与基线对比，并开展小规模教学试点，进一步验证工具在教学场景中的实际效果。
