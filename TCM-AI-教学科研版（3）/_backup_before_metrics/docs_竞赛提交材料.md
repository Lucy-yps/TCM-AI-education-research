## 一、学科需求分析（对应要求 1、3）

### 1.1 学科领域与应用场景界定

本作品聚焦**中医学**专业，具体落在**中医诊断学**的证型辨识环节，服务三类场景：

| 场景 | 使用者 | 传统做法 | 本工具做法 |
|---|---|---|---|
| 课堂教学 | 中医专业学生 | 翻阅教材/证型手册逐条比对 | 输入口语症状，毫秒级给出候选与证据 |
| 科研标注 | 研究者 | 人工逐条判读，无一致性工具 | 提供可追溯候选排序 + 置信度分级，供复核筛选 |
| 方法教学 | 教师 | 难以演示"分布失配"这类抽象概念 | 内置五种方法对比与路由实验，可现场演示 |

### 1.2 学科核心环节的痛点

1. **术语鸿沟**——患者口语（"没胃口"）与规范证型术语（"食少纳呆"）之间缺少稳定映射。本工具内置 107 条口语→规范词映射。
2. **证据不可追溯**——通用大模型能给出证型名，但说不清依据了哪些症状，学生无法据此学习。本工具对每条候选展示命中的症状词与未识别文本。
3. **过度自信**——多数工具不区分"有把握"与"在猜"。本工具用参考集实测准确率对置信度分级，证据不足时明确拒答。
4. **分布失配被忽视**——口语描述与电子病历文本分布差异极大，同一方法准确率可从 91.9% 跌到 12.7%。本工具把这一现象作为设计前提。

### 1.3 需求调研依据

痛点识别依据为 TCM-SD 公开数据集（5486 条真实电子病历）与自建教材体 37 例的实测分析，以及两类文本在术语覆盖率（19.6% vs 2.6%）、数字密度（0% vs 95.8%）上的量化差异。

> **说明：**本期未开展面向教师或学生的正式访谈/问卷，需求论证采用"教材研读 + 公开数据集量化分析"的替代方式（见《需求分析.md》4.4 节）。若后续补充正式调研，可在此处填写样本量、时间与主要结论。

## 二、AI 技术应用方案（对应要求 2、3）

### 2.1 技术选型与理由

| 技术 | 选型 | 理由 |
|---|---|---|
| 检索 | 词项 F1 / BM25 / TF-IDF / RRF 融合 | 无需训练、可解释、可离线；用于术语覆盖度高的口语输入 |
| 分类 | TF-IDF（char_wb 1-2gram）+ 逻辑回归 | 在 5455 条标注病历上训练，7.6 MB，单条推理约 7 ms，可离线 |
| 路由 | 可解释规则（知识库词覆盖密度 + 数字密度 + 病历结构词） | 两类文本分布差异大，单一方法无法兼顾；规则可解释、可复核 |
| 置信度 | 参考分布分箱 + 保序回归平滑 | 各方法分数量纲不同，固定阈值无意义；改为按档位实测准确率分级 |
| 大模型 | DeepSeek / 智谱 / ModelScope 三模型对照 | 仅用于对检索证据生成教学性摘要，不参与判定 |

### 2.2 与学科需求的适配性

不追求"更强的模型"，而是追求**教学场景需要的可解释与可复核**：每个候选都能追溯到命中的症状词，每个置信等级都能追溯到参考集实测准确率，每个数字都能由脚本复现。

## 三、作品功能说明（对应要求 3）

| 功能 | 说明 | 接口 |
|---|---|---|
| 知识检索与证型辨析 | 输入症状描述，输出候选证型、命中证据、未识别文本 | `POST /api/analyze` |
| 输入风格路由 | 自动判定口语/病历体，展示判定依据（覆盖密度、数字密度、结构词） | `POST /api/analyze` |
| 置信度分级与拒答 | 展示置信等级与该档实测准确率；证据不足时拒答并降级 | `POST /api/analyze` |
| 校准数据公开 | 原样暴露每个分数档对应的实测准确率 | `GET /api/calibration` |
| 知识图谱 | 证型—症状—方剂交互图谱（321 节点 / 344 关系） | `GET /api/graph` |
| 证型条目 | 37 个证型的症状、舌脉、方剂条目 | `GET /api/syndromes` |
| 教学性证据摘要 | 三家大模型对同一证据并发生成摘要，逐家显示状态 | `POST /api/analyze` |
| **辨证训练** | 从真实病历自动生成带解析的训练题；程序校验 + 选项位置随机化 | `POST /api/quiz/generate` |
| **相似证型鉴别** | 对比两个易混证型在真实病历中的高发症状；对知识库中定义相同的"同义词对"明确标注 | `GET /api/quiz/compare` |
| **学习进度追踪** | 记录每次答题，统计薄弱证型与易混淆证型对，支持定向补练 | `POST /api/quiz/record` |
| **方剂治法联想** | 练习证型↔治法↔方剂对应关系；干扰项取自相似证型 | `POST /api/quiz/formula` |
| **舌脉辨识** | 练习证型与舌脉表现的对应；舌脉特征来自真实病历统计 | `POST /api/quiz/tp` |

## 四、创新点与传统方式对比（对应要求 4）

### 4.1 三个创新点

1. **学科问题解决新方法：分布路由。** 发现并量化了"同一方法在不同文本分布下结论反转"（TF-IDF 在口语体 91.9%、病历体 12.7%），用可解释判据做路由，而不是选一个"最好的方法"。风格判定准确率 99.95%。
2. **教学科研新模式：把不确定性变成教学内容。** 置信度按参考分布分箱实测准确率分级，概率低于 0.50 时拒答——该区间实测准确率仅 55.4%，接近抛硬币。拒答机制本身即用于演示"证据不足时不下结论"的临床思维。
3. **技术应用新场景：以轻量模型对照大模型。** 在真实电子病历上，7.6 MB 可离线分类器 Top-1 93.0%，超过 DeepSeek 零样本 75.8% **17.2 个百分点**；而在口语输入上，三家大模型仅 37.8%~40.5%，低于 TF-IDF 检索 91.9% 约 50 个百分点。

### 4.2 对比传统学科建设方式

| 维度 | 传统方式 | 本作品 | 可验证依据 |
|---|---|---|---|
| 证型查阅效率 | 翻阅教材/手册，约数分钟/条 | 约 0.05 秒/条 | 实测接口响应 |
| 术语对照 | 依赖个人经验，无标准映射 | 107 条口语→规范词映射 | synonyms.json |
| 结果可追溯性 | 无法说明依据 | 展示命中症状词 + 未识别文本 | 前端结果卡 |
| 不确定性表达 | 无 | 置信度分级 + 拒答线 | calibration_data.json |
| 方法教学 | 难以演示分布失配 | 内置五方法对比与路由演示 | 测试案例/ 评测脚本 |
| 实验可复现性 | 依赖口头经验 | 全部脚本化，结果逐条落盘 | scripts/ + 测试案例/ |

**核心差异：**传统方式给出的是"结论"，本作品给出的是"结论 + 证据 + 把握程度 + 复现路径"，这四样恰好是教学与科研场景最需要的。

## 五、可行性与推广方案（对应要求 5）

### 5.1 复用条件

| 条件 | 要求 | 说明 |
|---|---|---|
| 硬件 | 普通笔记本即可 | 无需 GPU，分类器 7.6 MB |
| 软件 | Python 3.9+，5 个依赖 | 见 requirements.txt |
| 网络 | 可选 | 本地检索/分类/图谱完全离线；仅大模型摘要需联网 |
| 数据 | 自带 37 条知识库 | 更换 knowledge_base.json 即可迁移到其他证型体系 |
| 人力 | 1 人即可部署 | 双击启动，无需配置 |

### 5.2 实施成本

| 项目 | 成本 |
|---|---|
| 软件许可 | 0 元（全部开源依赖）|
| 硬件 | 0 元（复用现有电脑）|
| 大模型调用（可选）| 按量付费；本实验 686 条零样本评测的 token 消耗见 external_data/llm_baseline/ |
| 部署人力 | 约 0.5 人日（装依赖 + 启动）|
| 题库生成（可选）| 438 题实测约 **1.5~2.9 元**（单题 1,332 tokens）| 
| 迁移到新证型体系 | 约 1 人日（替换知识库 + 重跑校准脚本）|

### 5.3 落地路径

| 阶段 | 内容 | 周期 |
|---|---|---|
| 一、课堂演示 | 教师在中医诊断学课上演示检索与证据追溯 | 1 课时 |
| 二、学生自查 | 学生课后用工具对照教材核查证型与症状对应 | 1 学期 |
| 三、科研辅助 | 在证型相关研究中用于候选标注与一致性检查 | 按项目 |
| 四、横向复用 | 更换知识库，迁移到方剂学、针灸学等其他中医学科 | 1 人日/学科 |

**跨学科推广：**本项目"分布路由 + 准确率校准 + 拒答"框架与学科无关，可迁移到任何"训练分布与输入分布不一致"的教学科研文本场景（如法律文书检索、金融公告分析）。

## 六、规范、伦理与知识产权（对应要求 6）

### 6.1 数据来源与合法授权

| 数据 | 来源 | 许可 | 使用方式 |
|---|---|---|---|
| TCM-SD（5486 条真实病历）| Borororo/ZY-BERT 公开仓库 | **CC-BY-SA** | 二次加工用于训练与评测，已注明来源 |
| 教材体 37 例 | 本项目自建 | 项目自有 | 用于离线评测 |

**合规说明：**

- 本作品**不包含任何患者隐私数据**：TCM-SD 为已公开的脱敏数据集，教材体为本项目自行编写的演示病例。
- CC-BY-SA 为署名—相同方式共享许可，本作品在文档与代码注释中已注明来源（`eval_real.py`、`测试案例/eval_real_results.json`）。
- 如竞赛要求，可在提交包内附 `LICENSE` 或 `NOTICE` 文件进一步声明。

### 6.2 学术伦理

- **不作医学主张：**本作品不声称任何临床有效性，界面与文档均明确"不构成医学诊断或用药建议，不作为临床决策依据"。
- **不夸大指标：**主动披露多数类基线（77.3%）、macro-F1（71.4%）、分类器覆盖缺口（16/37 类）、数据划分缺陷（TCM-SD 官方划分非患者级，已剔除可见文本重叠后重测）。
- **可复现：**所有实验以脚本形式留存，逐条原始输出已保存，任何结论可被第三方复核。
- **不滥用大模型：**大模型仅用于生成教学性摘要，且在提示词中要求"证据不足时必须说明结果不可作为结论"。

### 6.3 符合学科规范与教育行业标准

- **术语规范：**证型名称采用知识库中的规范表述，并提供口语→规范词映射，符合中医诊断学术语习惯。
- **教学定位：**面向教学过程而非临床决策，不替代教材与教师，符合教育技术工具定位。
- **数据伦理：**不使用未授权的教学数据，不采集学生个人信息（如开展试点，建议匿名化处理）。
- **开源合规：**依赖库（Flask、scikit-learn、rank_bm25 等）均为允许商用的开源许可。
