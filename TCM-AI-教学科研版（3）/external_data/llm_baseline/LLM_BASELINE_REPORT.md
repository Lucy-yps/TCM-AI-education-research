# 大模型零样本基线对比实验

> 目的：回答一个必答题——这套轻量方案，比起直接问通用大模型，强在哪？

## 一、核心结论

- 病历体全量 683 条：轻量分类器 **93.0%**，DeepSeek 零样本 **75.8%**，分类器领先 **17.2 个百分点**。
- 分类器领先多数类基线（气滞血瘀 77.3%）15.7 个百分点。
- 通用大模型具备中医基础知识，但未见过本数据集的证型归一化规范，零样本直接提问显著弱于域内训练的轻量分类器。

## 六、成本对比

| 方案 | 推理成本 | 依赖 | 可解释性 |
|---|---|---|---|
| 轻量分类器 | 本机 CPU 约 7 ms/条 | 无外部依赖、可离线 | 可输出证据词与概率 |
| 大模型零样本 | 每次调用均需 API | 需网络与 Key | 黑盒，仅能给出结论 |

## 七、诚实的局限

- 分层抽样放大了稀有证型，抽样集准确率（DeepSeek 50.0%）低于全量（75.8%）；两个数字都要报，不能只挑一个。
- ModelScope 有速率限制，仅完成抽样集。
- 只测了零样本，未测少样本（few-shot）与微调，这是待补实验。
- 提示词会影响结果，本实验固定同一提示词以保证可比性。

## 八、对作品的结论

- 不要声称「我们的模型比大模型强」，而应声称：在真实电子病历的归一化证型分类任务上，一个 7.6 MB、可离线、单条推理 7 毫秒的轻量分类器，稳定超过通用大模型零样本 17.2 个百分点。
- 大模型在本作品中的正确定位是**辅助角色**：对检索证据做教学性摘要，而不是替代分类器。
