| | |
|---|---|
| **学科专业** | 中医学（中医诊断学 / 中医内科学方向）|

## 一、快速开始

```bash
# 1. 安装依赖（首次运行）
pip install -r requirements.txt

# 2. 启动服务
python server.py
# 或直接双击：启动.bat
```

浏览器打开：

| 界面 | 地址 | 功能 |
|---|---|---|
| **知识检索** | http://127.0.0.1:5000/ | 输入症状 → 候选证型 + 证据 + 置信度 |
| **本草科普样例库** | http://127.0.0.1:5000/#herb-library | 按材料类别浏览中草药参考图片与科普观察点 |
| **辨证训练** | http://127.0.0.1:5000/quiz.html | 从真实病历出题 → 答题 → 解析 |

主界面附有 25 个本草科普观察样例，按根/根茎、花叶与全草、茎皮与特殊材料、果实种子果皮、菌类分组。图片来自 Wikimedia Commons，卡片列出来源、贡献者及许可；图片仅供科普观察，不是药材标准图谱，也不能据此鉴定真伪、物种、产地或质量。浏览器需要联网加载参考图片；离线时知识检索和其他本地功能仍可使用。

## 二、作品简介

本作品解决中医诊断学教学中的两个具体问题：

1. **查证型效率低、证据不可追溯** —— 学生需要把口语化症状对应到规范证型，传统方式是翻阅教材逐条比对。
2. **优质辨证练习题稀缺** —— 编写一道带解析的病案题约需 30~60 分钟，难以批量供给。

**本作品的两条能力链路：**

```
真实病历 54,152 条（TCM-SD · CC-BY-SA）
        │
        ├──► ① 知识检索：口语输入 → 风格路由 → 检索/分类 → 置信度校准 → 拒答
        │         → 输出候选证型 + 命中证据 + 置信等级 + 依据说明
        │
        └──► ② 辨证训练：真实病历 → 约束生成 → 结构校验 → 训练题 + 逐项解析
                  → 学生答题 → 错题反馈
```

### 核心数据

| 指标 | 数值 |
|---|---|
| 知识库 | 37 个证型 / 248 症状词 / 107 条口语映射 |
| 分类器（域内监督）| Top-1 **93.0%**（95% CI: 90.8%~94.7%，去泄漏 686 例）|
| 大模型零样本（对照）| 75.8%；与多数类基线（77.3%）**无统计差异** |
| 风格路由准确率 | 99.95%（教材 37/37、病历 5482/5486）|
| 出题题库 | **151 题**，核心校验通过率 100%，覆盖 65/72 核心证型 |
| 出题成本 | 单题 1,332 tokens；438 题约 **1.5~2.9 元** |

## 五、项目结构

```
├── server.py            Flask 服务（10 个接口）
├── retrieval.py         检索层：路由 / 校准 / 拒答
├── quiz.py              出题引擎：生成与判定分离
├── main.html            知识检索、知识图谱与本草科普样例库界面
├── quiz.html            辨证训练界面
├── 启动.bat             一键启动
├── knowledge_base.json  37 个证型知识库
├── synonyms.json        107 条口语→规范词映射
├── calibration_data.json 置信度校准表
├── docs\               文档（11 份）与出题池数据
├── scripts\            实验脚本（7 个，均可复现）
├── 测试案例\            测试用例与评测结果
└── external_data\       模型、数据集、实验原始输出
```

## 六、可复现性

所有指标均可由脚本复现：

| 想复现什么 | 命令 |
|---|---|
| 检索/分类评测 | `python scripts/eval_real.py` |
| 大模型零样本基线 | `python scripts/llm_zeroshot.py` |
| 批量出题 | `python scripts/batch_generate.py . 100 5` |
| 题库质检报告 | `python scripts/qc_report.py . 20` |
| 成本测算 | `python scripts/cost_probe.py .` |
